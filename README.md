# 🪙 Metal & Tokenized Commodity Intelligence Agent (v1.3.0)

> **On-Chain Physical Assets (PAXG/XAUT), CoinGecko Metal Scanner & Global Commodity Supply Constraints Intelligence Engine with X402 Payment Retry Support.**

`Metal & Commodity Intelligence Agent` は、トークン化ゴールド/シルバー（PAXG, XAUT）のオンチェーンミント・バーン情報、CoinGecko API 経由の `gold-backed` / `commodity-backed` リアルタイム市場データ、COMEX金・銀保管庫の現物在庫推移、米国債債務状況、およびグローバル金鉱山採掘量と中央銀行による現物吸収率をリアルタイムで解析する自律型AI Agentです。同エコシステム内の **13-Chain** 分析基盤と連動し、13-Chain 監視の実行後に本エージェントのスキャンを実行する構成で組み込まれています[cite: 10]。

---

## 🚀 Key Features

* **Tokenized Metal On-Chain Surveillance:**
  * Ethereum 上の PAXG および XAUT のアクティブな Mint/Burn 状況のモニタリング[cite: 10]。
  * Gold/Silver Ratio（金銀比率）の計算とヒストリカルレンジ分析[cite: 10]。
* **CoinGecko Metal & Gold Category Scanner:**
  * `gold-backed` および `commodity-backed` カテゴリのトークン価格・24時間騰落率・出来高を自動追跡[cite: 10]。
  * 貴金属トークンの価格変動（+5%以上）を即座に感知し、シグナル生成[cite: 10]。
* **COMEX Vault & Central Bank Gold Analytics:**
  * COMEX（Registered Vault）における金・銀の物理現物在庫の引き出し傾向の追跡[cite: 10]。
  * 世界の中央銀行による四半期ごとの純買い増しデータ、脱ドル化（De-dollarization）トレード、および **X402 Protocol** 経由のエージェント決済・現物裏付け需要の分析[cite: 10]。
* **Mine Supply Bottleneck Dynamic Engine:**
  * 年間世界金鉱山生産量（~3,600t）に対する中央銀行の年間吸収量（~1,000t / 約27.8%）のリアルタイムタイトネス動的計算[cite: 10]。
  * 物理現物市場の供給制約（Critical Supply Crunch）シグナルの生成[cite: 10]。
* **US Debt Clock & Devaluation Index Integration:**
  * 米国債（$39.9T+）および日次利払い費（$3.5B+）のデータを自動取得し、ペーパーヘッジ（Paper to Silver Ratio）および法定通貨減価シグナル（Fiat Devaluation Signal）を算出[cite: 10]。
* **X402 / uAgents Retry Payment Protocol (NEW):**
  * クライアントエージェントからの着金通知（`CommitPayment`）に対し、最大3回（3秒間隔）の非同期リトライ検証を実施。
  * 決済未確定や遅延時のエラーハンドリング（HTTP 402 風の再試行要求通知）を実装し、コモディティインテリジェンス取引の信頼性を向上。
* **uAgents Protocol Native Support:**
  * `MetalDataQueryRequest` を受信後、シンボル（`PAXG`, `XAUT`, `GOLD`, `SILVER`, `ALL`）に応じて動的見積もり（0.2 ~ 0.5 FET）を行い、自律納品を実行[cite: 10]。
